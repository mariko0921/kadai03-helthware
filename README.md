# ①課題名

OGARU（自分の状態と向き合うアプリ）

## ②課題内容（どんな作品か）

- Oura Ringの健康データ、TANITAの体組成データ、ワンタップで記録した日々の気分を一元化して自分のリズムを知るためのダッシュボード。
- 自分が日々確認したい指標を中心に、身体の状態や変化を把握できるようにした。
- 外部サービスのAPIから取得したデータをFirebaseに保存し、グラフやカレンダーで可視化する。

## ③アプリのデプロイURL

https://kadai-wellness-mvp.web.app

## ④アプリのログイン用IDまたはPassword（ある場合）

Googleアカウントによるログインのため、専用のID・Passwordはなし。

## ⑤工夫した点・こだわった点

- 今回初めてClaude Codeを活用して開発を行った。
- データベースを利用するにあたり、どのようなデータ構造にし、どのように取得・活用するのかを理解しながら進めた。
  - データの種類・ユーザー・日付・取得元ごとに構造化。
- Firebaseのセキュリティルールの実装に挑戦した。
  - ログインしているユーザーのIDとアクセス先のユーザーIDが一致しているかを確認し、本人のみが読み書きできるように制御。
  - 保存するデータの形式や値を検証するバリデーションを実装。
- 保守性や今後の拡張性を考慮し、機能ごとにJavaScriptファイルを分割・連携させる構成を採用した。

## ⑥難しかった点・次回トライしたいこと（又は機能）

- 外部サービスとのAPI連携や、認証・セキュリティの仕組みについて、さらに理解を深めたい。
- 現在はPythonでAPIからデータを取得し、JSONファイルを介して取り込む仕様だが、今後はデータ連携の自動化に挑戦したい。
- 多くのユーザーが自身のウェアラブルデバイスや外部サービスのデータを連携できる仕組みに可能性を感じており、実現に向けて取り組みたい。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）

### 感想

今回初めてClaude Codeを本格的に活用し、自分が実現したいことが驚くほどのスピードで形になっていくことに、AI時代の開発の可能性を感じた。

これまでは、技術を理解してから実装すべきだと考えていたが、AIを活用して必要な技術や設計への理解を深めていくという学び方もあるのではないかと感じた。

基礎技術は自分でも実装できるように学習を続けつつ、今の自分の技術力で作りたいものを制限せずに積極的に形にしていきたい。
